# Assignment 4 - JavaScript Basics

## Description
This project was created for Assignment 4 to practice JavaScript basics, DOM manipulation, event handling, and interactive web development.

The website contains four pages with different JavaScript tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Features

### Part 1: JavaScript Basics (`index.html`)
- Using variables and operators
- Displaying messages with `console.log()` and `alert()`

### Part 2: DOM Manipulation (`dom.html`)
- Changing text content
- Changing background color
- Changing font size
- Adding and removing list items dynamically

### Part 3: JavaScript Events (`events.html`)
- Mouseover and mouseout events
- Displaying text while typing
- Calculator with four operations: `+`, `-`, `*`, `/`
- Handling empty inputs and division by zero

### Part 4: Interactive To-Do List (`todo.html`)
- Adding new tasks
- Marking tasks as completed
- Removing tasks
- Preventing empty tasks
- Clearing the input field after adding a task

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the navigation bar to switch between pages.
4. Test the interactive JavaScript features.
